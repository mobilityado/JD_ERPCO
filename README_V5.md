# CONCIL.IA V5 – Motor de conciliación manual

Esta versión ajusta el motor al ejemplo CUADRE ADO 14072026.

- El universo de conciliación parte de los conductores presentes en JDE.
- ERPCO no suma todos los descuentos para cotejar contra JDE.
- Conceptos conciliables detectados en el ejemplo manual: 853 PAGO X DAÑOS, 3220 ANTICIPO SUELDO, 741 EXC. INFONAVIT y 501 EXC. ISR.
- El total completo de adeudos ERPCO se conserva aparte para la Vista 360 y reportes.
- Para ampliar conceptos conciliables, editar CONCILIABLE_CODES en app.js.
