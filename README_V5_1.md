# CONCIL.IA V5.1 — Contraste adaptativo

Esta versión conserva intacto el motor de conciliación de la V5.

## Mejoras visuales
- Contraste reforzado en modo oscuro.
- Modo claro completamente revisado.
- KPIs con texto oscuro sobre tarjetas claras.
- Semáforo/gauge con porcentaje legible en ambos temas.
- Resumen ejecutivo y comparativo por marca adaptativos.
- Tablas, filtros y controles con contraste correcto.
- Vista 360° adaptada.
- Copiloto flotante adaptado.
- Tarjetas de archivos cargados mantienen el indicador verde.
- Scrollbars adaptativas.

No se modificó la lógica de conciliación ni la conexión de usuarios.
