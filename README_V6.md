# CONCIL.IA V6 — Executive Control

Esta versión conserva el motor de conciliación de la V5/V5.2.

## Novedades
- Resumen ejecutivo reforzado.
- Panel automático "Atención requerida" con los principales descuadres.
- Comparativo consolidado por marca ADO / AAO / TRT.
- Cambio de nombre a "Índice de conciliación".
- Modo Presentación Ejecutiva para ocultar controles operativos.
- Mejor jerarquía visual para revisiones gerenciales.
- Mantiene modo claro/oscuro, Copiloto, Vista 360 y exportación.

## Modo Presentación
Usa el botón `📺 Vista Ejecutiva` del encabezado para ocultar:
- Carga de archivos
- Filtros operativos
- Tabla detallada
- Paneles auxiliares

y mostrar una vista más limpia orientada a presentación.
